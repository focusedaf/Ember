# Ember

Ember is a Big Data Analytics project that analyzes large collections of manga, manhwa, manhua, web novels, and light novels to uncover patterns in genres, ratings, popularity, authors, release trends, and reader preferences.

## What Ember Analyzes

- Genre and category trends
- Ratings and popularity
- Author and creator performance
- Release and publication trends
- Chapter / volume patterns
- Genre combinations
- Popularity over time
- Reader preference patterns

## Data Pipeline

```text
Raw Data
   ↓
Data Collection
   ↓
Data Cleaning & Preprocessing
   ↓
Exploratory Data Analysis
   ↓
Big Data Processing
   ↓
Analytics
   ↓
Visualizations & Insights
```

## Key Questions

Ember aims to answer questions such as:

- Which genres dominate different formats?
- What factors correlate with higher ratings?
- How do popularity trends change over time?
- Which genre combinations are most common?
- How do manga, manhwa, manhua, and novels differ?
- What patterns can be found in reader preferences?

## Getting Started
